# 🍪 Cookie Notification - Premium Design Showcase

## ✨ Новые возможности дизайна

### 🎨 Визуальные улучшения

#### **Радужный градиент**
- Использование многоцветного градиента с зеленым, голубым, фиолетовым и розовым
- Плавные переходы цветов создают современный премиум вид
- Анимированные градиенты для динамического эффекта

#### **Стекломорфизм (Glassmorphism)**
- Полупрозрачный фон с эффектом размытия
- Многослойные градиенты для глубины
- Светящиеся границы с радужным эффектом

#### **3D эффекты**
- Объемные кнопки с тенями и подсветкой
- Плавающая иконка с вращающимся эффектом
- Декоративные элементы с анимацией вращения

### 🎭 Анимации и переходы

#### **Появление уведомления**
- Эластичная анимация с эффектом "bounce"
- Масштабирование от 0.8 до 1.05 и обратно к 1.0
- Плавное движение снизу вверх с задержкой

#### **Интерактивные элементы**
- Кнопки с эффектом "pulse" при наведении
- Масштабирование и подъем при hover
- Светящиеся эффекты и тени

#### **Декоративные анимации**
- 4 плавающих декоративных элемента
- Вращение и масштабирование с разными задержками
- Радужные тени и эффекты свечения

### 📱 Мобильная оптимизация

#### **Адаптивные размеры**
- Уменьшенные отступы и размеры на мобильных
- Вертикальное расположение кнопок
- Оптимизированные анимации для производительности

#### **Touch-friendly интерфейс**
- Увеличенные области нажатия
- Плавные жесты и переходы
- Отзывчивая обратная связь

### 🎯 Технические особенности

#### **Производительность**

## 🎭 Анимационные эффекты

### Основные анимации
1. **iconFloat** - Плавающая иконка (3s)
2. **iconRotate** - Вращение эффекта иконки (4s)
3. **titleShimmer** - Переливающийся заголовок (4s)
4. **titleUnderline** - Анимированная подчеркивание (2s)
5. **decorationFloat** - Плавающие декорации (6s)
6. **borderGlow** - Светящаяся граница (3s)
7. **buttonPulse** - Пульсация кнопок (0.6s)

### Переходы
- **slideInUp** - Появление (0.8s с bounce)
- **slideOutDown** - Исчезновение (0.4s)
- **Hover эффекты** - Масштабирование и подъем

## 🔧 Настройка и кастомизация

### Изменение цветов
```css
:root {
  --color-green: #YOUR_COLOR;
  --color-purple: #YOUR_COLOR;
  /* Обновите градиенты соответственно */
}
```

### Настройка анимаций
```css
.cookie-icon {
  animation: iconFloat 3s ease-in-out infinite;
  /* Измените 3s на нужную длительность */
}
```

### Отключение анимаций
```css
.cookie-notification * {
  animation: none !important;
  transition: none !important;
}
```
