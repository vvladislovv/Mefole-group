# 🍪 Cookie Notification - Исправление на полную ширину

## ✅ **Исправленные проблемы:**

### 🎯 **1. Полная ширина экрана:**
- **100vw ширина**: `width: 100vw !important`
- **Максимальная ширина**: `max-width: 100vw !important`
- **Минимальная ширина**: `min-width: 100vw !important`
- **Убраны ограничения**: `max-width: none !important`

### 📐 **2. Правильное позиционирование:**
- **Левая граница**: `left: 0 !important`
- **Правая граница**: `right: 0 !important`
- **Отступы**: `margin: 0 !important`
- **Box-sizing**: `box-sizing: border-box !important`

### 🎨 **3. Горизонтальная полоса:**
- **Flexbox**: `display: flex` для горизонтального расположения
- **Растягивание**: `flex: 1` для контента
- **Выравнивание**: `justify-content: space-between`
- **Отступы**: `padding: 16px 20px`

## 🔧 **Технические исправления:**

### **CSS принудительные стили:**
```css
.cookie-notification {
  position: fixed !important;
  top: 0 !important;
  left: 0 !important;
  right: 0 !important;
  width: 100vw !important;
  max-width: 100vw !important;
  min-width: 100vw !important;
  margin: 0 !important;
  padding: 16px 20px !important;
  box-sizing: border-box !important;
}
```

### **Контент на всю ширину:**
```css
.cookie-content {
  width: 100% !important;
  max-width: 100% !important;
  min-width: 100% !important;
  flex: 1 !important;
  display: flex;
  justify-content: space-between;
  align-items: center;
}
```

### **Убираем ограничения:**
```css
.cookie-notification,
.cookie-notification * {
  max-width: none !important;
  min-width: auto !important;
}
```
