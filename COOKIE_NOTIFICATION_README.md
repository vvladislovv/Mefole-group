# Cookie Notification System

## Описание

Система уведомления о куки для сайта MefoleGroup, которая соответствует дизайну и стилистике сайта. Включает в себя современные анимации, адаптивный дизайн и полную поддержку localStorage.

## Функциональность

### ✅ Основные возможности
- **Современный дизайн** - соответствует цветовой схеме сайта (зеленый #A6F00C и фиолетовый #8B5CF6)
- **Плавные анимации** - появление, исчезновение и интерактивные эффекты
- **Адаптивность** - оптимизировано для мобильных устройств
- **Локализация** - поддержка русского и английского языков
- **localStorage** - сохранение выбора пользователя
- **TypeScript поддержка** - типизированные хуки и компоненты

### 🎨 Дизайн и анимации
- Градиентные кнопки с эффектами наведения
- Пульсирующая иконка
- Светящийся заголовок
- Декоративные элементы
- Плавные переходы и трансформации

### 📱 Мобильная оптимизация
- Адаптивные размеры для всех экранов
- Оптимизированные анимации для производительности
- Вертикальное расположение кнопок на мобильных
- Уменьшенные отступы и размеры шрифтов

## Использование

### Базовое использование

```jsx
import CookieNotification from './components/CookieNotification';

function App() {
  return (
    <div>
      {/* Ваш контент */}
      <CookieNotification />
    </div>
  );
}
```

### Использование хука

```jsx
import { useCookieConsent } from './hooks/useCookieConsent';

function MyComponent() {
  const { 
    hasConsent, 
    needsConsent, 
    acceptCookies, 
    declineCookies 
  } = useCookieConsent();

  if (needsConsent) {
    return <div>Показываем уведомление о куки</div>;
  }

  if (hasConsent) {
    return <div>Пользователь принял куки</div>;
  }

  return <div>Пользователь отклонил куки</div>;
}
```

## API

### useCookieConsent Hook

```javascript
const {
  consent,        // 'accepted' | 'declined' | null
  isLoading,      // boolean
  hasConsent,     // boolean
  hasDeclined,    // boolean
  needsConsent,   // boolean
  acceptCookies,  // function
  declineCookies, // function
  resetConsent    // function
} = useCookieConsent();
```

### CookieNotification Props

Компонент не принимает пропсы, все настройки управляются через хук.

## Тестирование

### Автоматическое тестирование
1. Откройте `frontend/test-cookie-notification.html` в браузере
2. Используйте кнопки для тестирования localStorage
3. Проверьте сохранение состояния при перезагрузке

### Ручное тестирование
1. Запустите приложение в режиме разработки
2. Используйте тестовую панель в правом верхнем углу
3. Проверьте работу на разных устройствах

### Тестовые сценарии
1. **Первый визит** - уведомление должно появиться через 1 секунду
2. **Принятие куки** - уведомление исчезает, состояние сохраняется
3. **Отклонение куки** - уведомление исчезает, состояние сохраняется
4. **Перезагрузка** - уведомление не появляется повторно
5. **Очистка localStorage** - уведомление появляется снова

## Устранение неполадок

### Уведомление не появляется
1. Проверьте, что localStorage доступен
2. Убедитесь, что `cookieConsent` не установлен в localStorage
3. Проверьте консоль на ошибки

### Анимации не работают
1. Проверьте поддержку CSS transforms в браузере
2. Убедитесь, что CSS файл загружен
3. Проверьте, что нет конфликтов стилей

### Проблемы с мобильными устройствами
1. Проверьте viewport meta tag
2. Убедитесь, что touch события работают
3. Проверьте размеры на разных экранах
