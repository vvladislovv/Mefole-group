# 🍪 Руководство по тестированию уведомления о куки

## 🚀 Как протестировать уведомление

### 1. **Автоматическое тестирование в режиме разработки**
- Уведомление автоматически появится через 2 секунды после загрузки страницы
- В правом верхнем углу будет показана панель с текущим состоянием

### 2. **Ручное тестирование через консоль браузера**

Откройте консоль браузера (F12) и выполните команды:

```javascript
// Очистить состояние куки
clearCookieConsent();

// Перезагрузить страницу
window.location.reload();

// Или установить конкретное значение
setCookieConsent('accepted');
setCookieConsent('declined');

// Проверить текущее состояние
getCookieConsent();
```

### 3. **Тестирование через панель разработчика**

В правом верхнем углу есть панель с кнопкой "Reset & Reload":
- Показывает текущее состояние куки
- Кнопка очищает состояние и перезагружает страницу

## 🎯 Сценарии тестирования

### **Сценарий 1: Первый визит**
1. Очистите localStorage: `clearCookieConsent()`
2. Перезагрузите страницу
3. Уведомление должно появиться через 1.5 секунды

### **Сценарий 2: Принятие куки**
1. Нажмите кнопку "Принять"
2. Уведомление должно исчезнуть с анимацией
3. При перезагрузке уведомление не должно появляться

### **Сценарий 3: Отклонение куки**
1. Нажмите кнопку "Отклонить"
2. Уведомление должно исчезнуть с анимацией
3. При перезагрузке уведомление не должно появляться

### **Сценарий 4: Мобильные устройства**
1. Откройте DevTools (F12)
2. Переключитесь в режим мобильного устройства
3. Проверьте адаптивность дизайна

## 🔧 Отладка

### **Проверка состояния в консоли**
```javascript
// Посмотреть все данные localStorage
console.log(localStorage);

// Проверить конкретно куки
console.log('Cookie consent:', localStorage.getItem('cookieConsent'));

// Очистить все данные
localStorage.clear();
```

### **Проверка компонента**
В консоли браузера будут выводиться отладочные сообщения:
```
Cookie Notification Debug: {
  isLoading: false,
  needsConsent: true,
  isVisible: true,
  isAnimating: true
}
```

## 🚨 Возможные проблемы

### **Уведомление не появляется**
1. Проверьте консоль на ошибки
2. Убедитесь, что localStorage доступен
3. Проверьте, что `cookieConsent` не установлен
4. Попробуйте очистить localStorage

### **Анимации не работают**
1. Проверьте поддержку CSS в браузере
2. Убедитесь, что CSS файл загружен
3. Проверьте, что нет конфликтов стилей

### **Проблемы с мобильными**
1. Проверьте viewport meta tag
2. Убедитесь, что touch события работают
3. Проверьте размеры на разных экранах
